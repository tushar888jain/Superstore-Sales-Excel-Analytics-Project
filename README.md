# Superstore-Sales-Excel-Analytics-Project

An end-to-end Excel workbook built on the classic Superstore Sales dataset, covering the full range of core-to-advanced Excel techniques used in real analyst work. formulas, data cleaning, pivot tables, lookups, conditional logic, and dashboard-style summaries. Each section works through a specific set of Excel skills applied directly to the raw sales data, with explanations of the "why" alongside the "how."

# What's inside

Section 1 — Core Formulas & Aggregation SUM, MAX, MIN, SMALL, LARGE, MEDIAN, and TRANSPOSE applied to monthly sales figures, with a comparison of manual transpose vs. the TRANSPOSE formula, and growth % vs. CAGR calculations.

Section 2 — Formatting & Format Painter Efficient formatting workflows across large datasets using Format Painter, and why it matters for consistency at scale.

Section 3 — Sorting Single-column, color-based, and multi-level sorting, with a look at how sort order changes data interpretation.

Section 4 — Date Functions Manual date duration calculations vs. DATEDIF, and why built-in date functions matter for accuracy and speed.

Section 5 — Logical Functions Combining IF, AND, OR, and IFERROR to build robust conditional logic for real-world data checks.

Section 6 — Text Functions & Data Cleaning SEARCH vs. FIND, Go To Special, Text to Columns, CONCATENATE vs. the & operator, and Find & Replace for cleaning messy data.

Section 7 — Pivot Tables Pivot Table components, grouping for better summarization, handling blank cells, and combining custom grouping with conditional formatting.

Section 8 — Lookups VLOOKUP syntax, exact vs. approximate match, and VLOOKUP vs. HLOOKUP for pulling data across tables.

Section 9 — Conditional Aggregation COUNTIF, SUMIF, and AVERAGEIF compared, plus why COUNTIFS/SUMIFS matter once you need multiple criteria.

Section 10 — Conditional Formatting Icon sets used to visualize sales trends at a glance.

Section 11 — Data Consolidation Using the Consolidate feature to merge and summarize data from multiple ranges/sheets.

Appendices 1–5 Supporting raw data tables referenced throughout the sections above.


# Tools & techniques demonstrated

Formulas & functions · Sorting & filtering · Pivot Tables & grouping · VLOOKUP/HLOOKUP · Conditional logic (IF/AND/OR/IFERROR) · Text functions & data cleaning · Conditional formatting · Data consolidation

# About

Built as a hands-on practical project to demonstrate applied Excel skills across an 11-section workflow, using a single sales dataset from raw data through to structured, formula-driven analysis.
